# Gemini Embedder

Provides Google Gemini embeddings via the embedding-001 model

**Inputs**

- none

**Outputs**

- Embedder: an embedding model for Text Embedder or Reference Library

Provides embeddings from Google's `embedding-001` model. It needs a Gemini API key: use **Configure API Keys...** (or
**Options > Preferences > API Keys**) to enter it. Until a key is set the widget outputs no embedder. Documents are sent
to Google's servers.
