# SBERT Embedder

Provides the sentence-transformers embedder model

**Inputs**

- none

**Outputs**

- Embedder: an embedding model for Text Embedder or Reference Library

Provides the `all-MiniLM-L6-v2` [sentence-transformers](https://www.sbert.net) model. Vectors are L2-normalized. The
model is downloaded on first use. The widget has no settings.
