# OpenAI Embedder

Provides the OpenAI embedding model

**Inputs**

- none

**Outputs**

- Embedder: an embedding model for Text Embedder or Reference Library

Provides OpenAI embeddings. Choose the **Embedding Model** (the default is `text-embedding-3-small`) and use
**Configure API Keys...** (or **Options > Preferences > API Keys**) to enter your OpenAI API key. Until a key is set the
widget outputs no embedder. Documents are sent to OpenAI's servers.
